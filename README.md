# atlas-notes

Atlas is a minimal notes app — sign up, jot notes, pin the important ones, archive the rest.

**Stack:** Next.js 15 (App Router, TypeScript)

It is intentionally small. The user-action handlers log to the console.

## Key user actions

sign up · log in · create note · pin note · archive note

## Running it

```bash
npm install
npm run dev   # http://localhost:3000
```
